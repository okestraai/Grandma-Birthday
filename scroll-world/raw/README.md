# Drop your Higgsfield downloads here

Name each file exactly like this, so they're matched to the right step:

| What | File name |
|---|---|
| Scene pictures | `still-1.png` … `still-5.png` |
| Wide clips (16:9) | `wide-1.mp4` … `wide-5.mp4` |
| Tall phone clips (9:16) | `tall-1.mp4` … `tall-5.mp4` |

After each clip, tell Claude. It pulls out the clip's last frame into `../frames/`, which you
upload as the start frame of the next clip.
